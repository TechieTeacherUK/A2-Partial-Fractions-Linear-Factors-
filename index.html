Theory & Key Rules

Cheat Sheet
1

Check Fraction Degree

Must be a proper fraction ($$\text{degree of numerator} < \text{degree of denominator}$$).

If improper, perform polynomial division first!
2

Linear Factor Form

Assign a constant numerator ($$A, B, C$$) to each distinct linear factor in the denominator.

$$\frac{px + q}{(ax + b)(cx + d)} \equiv \frac{A}{ax + b} + \frac{B}{cx + d}$$
3

Solving for Constants

Clear denominators by multiplying through, then use strategic substitution ($$x = \text{root}$$) to eliminate terms.

$$px + q \equiv A(cx + d) + B(ax + b)$$

Lesson Worked Examples

Step 1: Set up the identity

$$\frac{7x - 2}{(x - 2)(x + 3)} \equiv \frac{A}{x - 2} + \frac{B}{x + 3}$$

Step 2: Clear denominators

$$7x - 2 \equiv A(x + 3) + B(x - 2)$$

Step 3: Substitute values

  • Sub $$x = 2 \implies 7(2) - 2 = A(5) \implies 12 = 5A \implies A = \frac{12}{5}$$
  • Sub $$x = -3 \implies 7(-3) - 2 = B(-5) \implies -23 = -5B \implies B = \frac{23}{5}$$

$$\text{Final Result: } \frac{12}{5(x - 2)} + \frac{23}{5(x + 3)}$$

Step 1: Factorise denominator first

$$2x^2 - 5x - 3 = (2x + 1)(x - 3)$$

$$\frac{4x + 10}{(2x + 1)(x - 3)} \equiv \frac{A}{2x + 1} + \frac{B}{x - 3}$$

Step 2: Clear denominators & solve constants

$$4x + 10 \equiv A(x - 3) + B(2x + 1)$$

  • Sub $$x = 3 \implies 4(3) + 10 = B(7) \implies 22 = 7B \implies B = \frac{22}{7}$$
  • Sub $$x = -\frac{1}{2} \implies 4(-\frac{1}{2}) + 10 = A(-\frac{7}{2}) \implies 8 = -\frac{7}{2}A \implies A = -\frac{16}{7}$$

$$\text{Final Result: } -\frac{16}{7(2x + 1)} + \frac{22}{7(x - 3)}$$

Step 1: Set up three linear terms

$$\frac{3x^2 + 8x - 5}{(x - 1)(x + 2)(x + 3)} \equiv \frac{A}{x - 1} + \frac{B}{x + 2} + \frac{C}{x + 3}$$

Step 2: Clear denominators

$$3x^2 + 8x - 5 \equiv A(x + 2)(x + 3) + B(x - 1)(x + 3) + C(x - 1)(x + 2)$$

Step 3: Solve for $$A, B, C$$

  • Sub $$x = 1 \implies 6 = A(3)(4) \implies 12A = 6 \implies A = \frac{1}{2}$$
  • Sub $$x = -2 \implies -9 = B(-3)(1) \implies -3B = -9 \implies B = 3$$
  • Sub $$x = -3 \implies -2 = C(-4)(-1) \implies 4C = -2 \implies C = -\frac{1}{2}$$

$$\text{Final Result: } \frac{1}{2(x - 1)} + \frac{3}{x + 2} - \frac{1}{2(x + 3)}$$
